# 🎓 HTML & JavaScript Grundkurs

Ein projektbasierter Web-Entwicklungs-Kurs für Anfänger — konzipiert für Applikationsentwickler-Lehrlinge im 1. Lehrjahr.

**Von Null zu einer echten Web-App in 12 Lektionen.**

🇬🇧 [English version](README.en.md)

---

## 📖 Über den Kurs

Dieser Kurs bringt dir HTML, CSS und JavaScript bei — nicht durch trockene Theorie, sondern durch **echte Projekte**, die du selbst baust. Am Ende hast du:

- ✅ Solide Grundlagen in HTML, CSS und JavaScript
- ✅ Erfahrung mit modernen Konzepten (Flexbox, State-Pattern, APIs)
- ✅ **12 fertige Projekte**, die du zeigen kannst
- ✅ Ein eigenes Abschlussprojekt für dein Portfolio

**Kein Framework-Overload.** Kein `npm install` von 300 MB. Nur Browser + VS Code + deine Neugier.

---

## 🎯 Für wen ist der Kurs?

- **Applikationsentwickler-Lehrlinge (EFZ)** im 1. Lehrjahr

- **Umsteiger**, die Web-Entwicklung von Grund auf lernen wollen

**Vorwissen:** Keins. Du solltest einen Computer bedienen können — das war's.

## 📂 Ordner-Struktur pro Lektion

Jede Lektion ist gleich aufgebaut:

```
lektion-XX-thema/
├── README.md              → Theorie, Lernziele, Anleitung
├── beispiel/              → Fertiges Beispiel-Projekt
│   ├── index.html
│   ├── style.css
│   └── script.js
├── uebungen/              → 3 Übungen mit steigender Schwierigkeit
│   ├── uebung-1.md        → Einfach, geführt
│   ├── uebung-2.md        → Mittel
│   └── uebung-3.md        → Frei / kreativ
└── loesungen/             → Musterlösungen für alle Übungen
    ├── uebung-1/          → mit LOESUNG.md für Erklärungen
    ├── uebung-2/
    └── uebung-3/
```

**Wichtig:** Musterlösungen erst anschauen, wenn du wirklich stecken bleibst. Der Lerneffekt kommt vom **selber machen**.

## 🚀 Wie du den Kurs durchgehst

### Für jede Lektion:

1. **README.md lesen** — Theorie und Lernziele verstehen
2. **`beispiel/`** anschauen — im Browser öffnen, im Code stöbern
3. **Übung 1** machen (geführt, mit Anleitung)
4. **Übung 2** machen (mittelschwer)
5. **Übung 3** machen (frei / kreativ)
6. **Bei Bedarf:** Musterlösung vergleichen
7. **Checkliste** am Ende des README abhaken
8. **Nächste Lektion**

### Tempo

- **Empfohlen:** 1 Lektion pro Woche → 12 Wochen für den ganzen Kurs
- **Intensiv:** 1 Lektion pro Tag → 12 Tage
- **Nebenbei:** Wie es passt — kein Druck

Wichtiger als Tempo ist **Kontinuität**. Lieber 30 Minuten jeden Tag als 5 Stunden am Sonntag.

---

## 🎨 Prinzipien des Kurses

1. **Projektbasiert** — Von Tag 1 baust du was Sichtbares
2. **Kein Framework-Overload** — Reines HTML/CSS/JS. Frameworks kommen im nächsten Kurs.
3. **Kleine Schritte** — Ein Konzept pro Lektion
4. **Praxis vor Theorie** — Erst machen, dann verstehen
5. **Sprechende Namen** — Deutsche Variablen, kein `x` und `tmp`
6. **DevTools früh** — Ab Lektion 2 F12 auf, alles anschauen
