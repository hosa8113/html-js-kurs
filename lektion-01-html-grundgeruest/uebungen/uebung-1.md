# Übung 1 — Steckbrief nachbauen

**Schwierigkeit:** Einfach
**Zeit:** ca. 15 Minuten

## Aufgabe

Baue eine eigene Steckbrief-Seite nach dem Vorbild im Ordner `beispiel/`.

**Ersetze alle Angaben mit deinen eigenen** — Name, Alter, Hobbys, Lieblingssprachen, Kontakt.

## Anforderungen

Deine Seite muss folgende Tags enthalten:

- [ ] `<!DOCTYPE html>` ganz oben
- [ ] `<html lang="de">`
- [ ] `<head>` mit `<meta charset="UTF-8">` und `<title>`
- [ ] `<body>` mit sichtbarem Inhalt
- [ ] Mindestens 1× `<h1>`
- [ ] Mindestens 2× `<h2>`
- [ ] Mindestens 2× `<p>`
- [ ] Mindestens 1× `<ul>` mit `<li>`
- [ ] Mindestens 1× `<a href="...">` (funktionierender Link)
- [ ] Die semantischen Tags `<header>`, `<main>` und `<footer>`

## Erwartetes Ergebnis

Wenn du die Datei mit **Live Server** öffnest, siehst du:

- Deinen Namen als grosse Überschrift
- Mehrere Abschnitte mit Zwischenüberschriften
- Deine Hobbys als Aufzählung mit Punkten
- Mindestens einen anklickbaren Link

Die Seite ist noch **komplett ungestylt** (schwarzer Text auf weissem Grund, Times-New-Roman-Look) — das ist normal! CSS kommt in Lektion 2.

## Hinweise

- **Emmet-Trick:** Tippe `!` und drücke `Tab` → VS Code erstellt automatisch das Grundgerüst
- Vergiss die schliessenden Tags nicht (`</p>`, `</ul>`, ...)
- Speichern nicht vergessen (`Ctrl+S`)
- Live Server aktualisiert automatisch, wenn du speicherst

## Stuck? Was tun?

1. **Vergleiche mit `beispiel/index.html`** — was ist anders?
2. **DevTools öffnen** (F12) → Tab "Console" → gibt's rote Fehlermeldungen?
3. **Frag Google** — z.B. "html link erstellen"
4. **Erst dann** in `loesungen/uebung-1/` schauen
