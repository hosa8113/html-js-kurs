# Übung 3 — Eigene Themenseite bauen

**Schwierigkeit:** Frei
**Zeit:** ca. 15 Minuten

## Aufgabe

Bau eine **komplett eigene** HTML-Seite zu einem Thema, das dich interessiert. Kein Steckbrief mehr — irgendwas Neues.

**Ideen:**

- Eine Fanseite zu deinem Lieblingsgame / Band / Serie / Auto
- Ein Rezept für dein Lieblingsessen (mit nummerierten Schritten!)
- Eine "Top 10" Liste zu irgendwas (Filme, Städte, Snacks, ...)
- Eine Anleitung zu etwas, das du kannst (Skate-Trick, Gitarrenakkord, ...)
- Eine kleine "Über meine Katze/Hund"-Seite

## Anforderungen

Deine Seite muss:

- [ ] Ein sauberes HTML-Grundgerüst haben
- [ ] Mindestens **6 verschiedene Tag-Arten** verwenden (nicht mitzählen: `<html>`, `<head>`, `<body>`, `<meta>`)
- [ ] Mindestens **eine Liste** (`<ul>` oder `<ol>`)
- [ ] Mindestens **einen Link** nach aussen
- [ ] Mindestens **ein Bild**
- [ ] Die semantischen Tags `<header>` und `<main>` verwenden

## Erwartetes Ergebnis

Eine Seite, die du **jemandem zeigen willst**. Kein Copy-Paste vom Steckbrief.

## Hinweise

- **Denk zuerst nach**, bevor du tippst: Was ist der Titel? Welche Abschnitte hat die Seite?
- **Mach eine kurze Skizze auf Papier** — Struktur first, Code second.
- **Nutze DevTools** um zu prüfen: passt die Struktur? Sind alle Tags richtig geschlossen?

## Bonus-Herausforderungen

- **Zwei Seiten:** Bau eine zweite HTML-Datei und verlinke die beiden Seiten gegenseitig.
- **Kommentare:** Nutze HTML-Kommentare (`<!-- ... -->`) um Abschnitte zu beschriften.
- **Ordner-Struktur:** Lege deine Bilder in einen Unterordner `bilder/` und referenziere sie richtig (`<img src="bilder/foto.jpg">`).

## Was du damit später machst

Diese Seite ist deine **erste eigene Webseite**. Behalte den Ordner — in Lektion 2 machen wir sie mit CSS hübsch, in Lektion 5 fügen wir Interaktion mit JavaScript hinzu.
